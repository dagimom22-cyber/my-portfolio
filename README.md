# Dagmawit's Portfolio

A responsive personal portfolio built with React and Vite.

## Run locally

1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal.

## Before publishing

- Replace the placeholder email and social profile details in `src/components/Contact.jsx` with your real details.
- Add your real GitHub and live-demo URLs in `src/data/projects.js` when they are available.
- Check that every project description accurately reflects your own work.

Build for deployment with `npm run build`.
